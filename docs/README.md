# XeCMS 문서

이 디렉터리는 XeCMS 정식 릴리스에서 제공할 공개 도움말 문서를 관리한다.
현재 `0.4.1`은 소스 저장소 실행을 지원하는 개발 단계이므로, 설치와 개발에 필요한
기본 정보는 우선 [프로젝트 README](../README.md)에서 제공한다.

정식 배포 준비와 함께 다음 문서를 순차적으로 추가한다.

- 설치와 최초 설정
- Upgrade와 Migration
- 운영, Backup과 복구
- 콘텐츠 모델과 권한 구성
- REST API와 TypeScript API
- Plugin 및 Custom Admin App 개발

공개되지 않은 설계 초안이나 시점에 따라 달라질 수 있는 내부 개발 메모는 이 디렉터리에
포함하지 않는다. 공개 문서로 확정된 내용만 추가하며, 저장소의 로컬 링크 검사를 항상
통과하도록 유지한다.
