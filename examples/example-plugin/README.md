# @xecms/example-plugin

XeCMS Trusted Plugin 계약과 lifecycle을 보여 주는 공식 참조 Plugin입니다.

2.x 패키지는 XeCMS 0.6.x용이며, 기존 XeCMS 0.5.x 프로젝트는 1.x를 유지합니다.
기본 엔진에는 포함되지 않으므로 필요한 프로젝트에서 설치하고 `xecms.config.json`의
`plugins` 배열에 `"@xecms/example-plugin"`을 등록합니다.

새 Plugin을 만들 때는 이 패키지의 소스와
[확장 개발 문서](https://github.com/mkjang2000/XeCMS/blob/main/docs/extending.md)를 참고하세요.
