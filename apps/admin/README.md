# @xecms/admin-app

XeCMS 서버가 `/admin` 경로에서 제공하는 엔진 관리 UI 번들입니다.
Schema·콘텐츠·인증/권한·운영·플러그인을 관리하며, 업무 화면 빌더는 포함하지 않습니다.
선택 서버 확장의 관리 화면은 서버가 제공하는 확장 링크를 통해 별도 번들로 엽니다.

일반적으로 직접 실행하지 않고 `pnpm create xecms`가 생성한 프로젝트에서 사용합니다.

```bash
pnpm create xecms my-cms
```

설치와 배포 절차는 [XeCMS 문서](https://github.com/mkjang2000/XeCMS/tree/main/docs)를
참고하세요.
